# Where boards live

Your boards are ordinary files on your Mac. LYRIKAI board keeps them in a **boards folder** you can open in Finder at any time.

## The boards folder

When you first save, the app creates a folder for your work. Every board in the library sidebar comes from a file in that folder. The sidebar shows **Boards folder** at the bottom — tap it to reveal the folder in Finder.

## Portable `.lkmindmap` files

Each board is saved as a single **`.lkmindmap`** file. That file holds your drawing, embedded images, camera position, and theme — everything needed to reopen the board elsewhere. Copy a file to back it up or move it to another Mac with LYRIKAI board installed.

## No account required

Nothing is uploaded to a service for storage. There is no login step and no remote library. If you can see the file in Finder, you have the board.
