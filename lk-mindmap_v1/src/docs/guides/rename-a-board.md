# Rename a board

1. Open the board you want to rename.
2. Click the title in the **top bar**, type the new name, then click away from the field (or press **Return**).
3. Wait for **All changes saved** — the file on disk renames to match.
4. **From the library** — click the **pencil** on a board row, type the new name, and confirm (blur or Return).
5. **From the overflow menu** — click **⋯** in the top bar, choose **Rename**, enter the new name, and confirm.

If a board with that name already exists, pick a different title. Renaming never silently overwrites another board.
