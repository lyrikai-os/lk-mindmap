# When save fails

The top bar shows **Save failed** and a dialog appears. Your edits are still on screen — nothing is lost yet.

1. Read the message. Common causes: disk full, permission denied, or the file changed outside the app.
2. Click **Retry save** to try writing again (fix disk space or permissions first if needed).
3. If retry keeps failing, click **Save as…** and choose a new location or filename. Your work is written to the new file.
4. Click **Keep editing** to dismiss the dialog and continue working. The board stays unsaved until a save succeeds.
5. If you were switching boards or closing the app, **Discard changes & continue** lets you leave without saving — only use this if you accept losing unsaved edits.

After a successful save, the top bar returns to **All changes saved**.
