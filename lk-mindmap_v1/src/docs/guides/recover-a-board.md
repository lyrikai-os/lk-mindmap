# Recover a board

Use this when a board will not open or the library shows **Needs recovery**.

1. Click the board in the library (or try to open the `.lkmindmap` file).
2. A dialog explains what went wrong. If a recovery copy exists, click **Open recovery copy**.
3. LYRIKAI board loads the backup and saves it as a **new** board file (the title includes *recovered*).
4. Check that your ideas look right, then save or rename the recovered board.
5. In Finder, the recovery copy lives next to the original — same filename with **`.bak`** added. Keep that file until you trust the recovered board.

If no recovery copy is offered, the file may be too damaged. Try an older backup you copied elsewhere.
