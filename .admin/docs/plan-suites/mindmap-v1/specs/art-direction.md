# Art direction — a personal working board

Thesis: the board is the application. Give ideas the largest surface; compact file controls and three expandable tool shelves should make drawing, mapping, and collecting immediately legible. No marketing landing page or dashboard wrapper.

Use a restrained graphite navigation surface, clear neutral light canvas, and mint/teal active accents. Provide a dark board alternative with elevated neutral surfaces and readable contrast. These are product-local directions, not invented Hive registry IDs. Define semantic tokens for shell, surface, board background, text, muted text, border, accent, and focus. Custom board theme controls change canvas appearance independently of toolsets; preserve authored content colors.

Type: macOS system sans for compact utility text; locally bundled Excalidraw fonts for authored board content. The small LYRIKAI board wordmark may use tracking and weight without introducing a decorative hero display. Comfortable canvas, compact tools, modest radii. Selection, save status, expansion states, and focus are functional marks. Transitions at most 150ms and respect reduced motion.

Brand test: first view shows a usable board, a recognizable LYRIKAI board label, board file status, and the three named tool shelves. It should be clear within ten seconds how to add an idea and where it saves. Themes must not act as modes that hide another toolset.

Avoid (applications of Precision, not a second governing rulebook): purple-on-white or purple-indigo glow; Inter/Roboto/Arial hero display; cream+terracotta or cream+serif broadsheet; glass-card stacks and badge clutter as design. Also avoid unlabeled primary icons and theme changes that erase user styling.
