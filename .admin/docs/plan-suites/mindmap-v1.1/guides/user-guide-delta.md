# User guide — v1.1 delta

Baseline: [mindmap-v1/guides/user-guide.md](../../mindmap-v1/guides/user-guide.md). Owner-facing delta for polish.

## New / clarified

| Topic | Guidance |
|-------|----------|
| Rename | Rename from the library pencil control, overflow **Rename…**, or edit the topbar title and leave the field |
| Library dates | Dates reflect last successful save |
| Pinboard caption | Select an image, then **Caption image** in Pinboard |
| Sketchbook preset | **Soft stroke preset** sets stroke feel for new marks |
| Theme presets | Choose Paper / Graphite / Night, or tune background, grid color, grid type, and gap; your object colors stay yours |
| Docs / Help | Open Docs from the help icon or overflow **Help / Docs**; read About, Explainers, Guides offline; Esc closes |

## Unchanged walls (disclose)

No account. Boards live in your boards folder. No collaboration. No automatic layout. Package may be unsigned.
