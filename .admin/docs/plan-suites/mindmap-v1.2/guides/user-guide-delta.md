# User guide delta — v1.2

Baseline Docs / guides from v1.1. Delta for owners after v1.2 ships:

## What you’ll notice

- Opening and closing the **library** and **Docs** feels smoother — brief motion, not a new UI.
- Error/save attention dialogs ease in rather than hard-pop.
- If your Mac has **Reduce motion** enabled, the app skips the flourishes and shows the final layout immediately.

## What did not change

- Boards, files, themes, toolsets, and Excalidraw drawing behave as in v1.1.
- Docs remain offline and bundled.
- No account, cloud sync, or collab.

## Version

Product label: **LYRIKAI board v1.2** (shell motion). Not a separate “GSAP experiment” product.
